# Hormozi Frameworks ($100M Offers / Leads / Money Models)

## Overview

Verified distillations of Alex Hormozi's three Acquisition.com books. Each reference file was extracted from the full book text and adversarially fact-checked against it: formulas, step counts, step order, and every number are the book's, not approximations.

**Trust these files over memory.** Training-data recall of these books is unreliable — especially $100M Money Models (2025). If an answer isn't grounded in a reference file here, it is a guess.

## The spine — how the three books connect

- **Offers** — WHAT you sell, to whom, at what price. Value Equation, Grand Slam Offer, pricing, scarcity/urgency/bonuses/guarantees, naming.
- **Money Models** — HOW the first ~30 days of purchases are sequenced (attraction → upsell → downsell → continuity) so gross profit from a new customer pays for acquiring the next one (client-financed acquisition).
- **Leads** — HOW strangers find out. Lead magnets, the Core Four channels, Rule of 100, then the four Lead Getters to scale.

Build order when constructing or rebranding a business: **market → offer → money model → leads**. Great leads cannot save a bad offer; a great offer without a money model stays cash-constrained.

## Operating rules

1. Read the relevant reference section BEFORE advising. Never answer from general marketing knowledge when a framework exists here.
2. Name the framework you are applying and follow its exact steps in order. Partial application (e.g., an offer stack without trim & stack, a guarantee without a conditional structure) loses most of the value.
3. Show the math when a rule exists: Value Equation scoring, LTGP:CAC ≥ 3:1, the 30-day CFA check, Rule of 100, growth-cap formula. Numbers beat adjectives.
4. Diagnosis requests → run Playbook 1 in playbooks.md, don't ad-hoc it.
5. Resist discount instincts. Before ever lowering a price, check the Virtuous Cycle of Price (offers.md §4) and the bonus rules (offers.md §11) — the book's answer is almost always add value or add a bonus, never cut price.
6. Copy/website tasks → Playbook 5: headline from M-A-G-I-C, body from the Value Equation, risk reversal from the guarantee catalog, CTA from scarcity/urgency rules.
7. Keep the user's actual constraints in the math (team size, cash, fulfillment capacity). Hormozi's decision rules fork on these — use the forks, don't average them.

## Common mistakes

| Mistake | Correction |
|---|---|
| Generic marketing advice with Hormozi vocabulary sprinkled on | Every recommendation must trace to a specific framework, section, and rule |
| Working on leads before the offer is fixed | Spine order: offer → money model → leads (playbooks.md) |
| A single front-end offer with nothing behind it | Every offer needs a money model: upsell/downsell/continuity sequencing (money-models.md) |
| Recalling frameworks from memory ("I think it's 4 steps…") | Read the file; step counts and numbers here are verified against the books |
| Treating benchmarks as decoration | Benchmarks are gates: 3:1 LTGP:CAC, 30-day cash > CAC (+ fulfillment), Rule of 100 — check them explicitly |
| Presenting price before value | Value Equation stack first, price last, price anchored against the stack |
